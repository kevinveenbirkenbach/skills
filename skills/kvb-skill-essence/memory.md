# Memory scope

Memory files load on recall: lowest leverage, and where cutting evidence does
the most damage.

## Doctor

- A `MEMORY.md` pointer whose file is gone; a memory file no pointer names.
- A dead `[[wikilink]]`: no memory of that name exists.
- A memory citing a `file:line`, function or flag that no longer exists.
  Verify against the current tree, through the codebase-memory-mcp graph first
  (`search_graph`, `trace_path`; the `kvb-agent-optimize` skill sets it up),
  grep and read after. A stale citation is worse than none: it reads as
  checked.

## Compact

- Keep the **why** and evidence behind a memory: the date, the incident, the
  quoted correction. A rule stripped of evidence degrades into an exhortation
  and stops changing behaviour.
- Never merge two memories whose evidence differs: two incidents behind one
  rule are stronger than one; two rules sharing one incident is a fabrication.
- `MEMORY.md` stays at most 400 words: one line per section linking its
  sub-index, plus only the rules every session needs on every turn; details
  go into the sub-indexes.
